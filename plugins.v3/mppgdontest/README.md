# MPPGDON 网盘搜索 v0.6.0

侧栏入口改为「发现」。分享同步不再填写固定 STRM 目录，按电影/电视剧根目录、已有索引和季号生成目标，再应用 MP→CMS 映射。结果行显示目标；真实同步时 MP 创建缺少的目录，CMS 负责生成 STRM。多季整包暂不自动拆分。清晰度改为六项多选，默认 4K、2K、1080。

「媒体库」标签支持手动只读扫描，SQLite 记录目录、STRM、NFO 和图片。NFO 有效但缺图仍标为已刮削并注明缺失。MP前缀#CMS前缀 的转换现在同时用于预览和实际同步。

管理员在插件连接设置中保存 CMS 根地址、网页登录 Bearer Token、CID、电影/电视剧根目录及映射后，即可点击结果行的「分享同步」。默认演练，勾选真实提交后才会调用 CMS。「已受理」不代表 STRM 已生成。不使用 Cookie 或转存 API Token。

网盘结果弹窗在窗口内居中；点击统计旁的「展开重复」可比较同一分享的重复来源记录，不改去重规则。

更新并启用后刷新 MP，点击侧栏「发现」进入。按类型、排序、风格、语言和最低评分筛选，或直接查询片名；点击海报就在当前页按片名和年份搜索 115。TMDB 沿用 MP 的连接，不改原生探索页。

在配置页启用并保存，打开详情页输入片名后点击“搜索资源”。可按年份及4K/1080p筛选，查看、复制或打开115分享。默认PanSou为 https://pansou.tiandechi.com ，公开服务Token留空；自建服务填写服务根地址与可选认证Token。

保留原安装测试版ID MppgdonTest，原位更新即可。搜索仅展示资源，不核实实际文件、链接有效性或库存；本版没有CMS转存功能。完整说明见仓库根README。
