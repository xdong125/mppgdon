# MPPGDON 安装测试

版本：0.1.0。支持 MoviePilot V3（>=3.0.0,<4）。

安装后打开配置，填写“测试展示文本”、启用并保存。详情页显示插件版本、启用状态与配置文本。刷新后再次打开配置，检查文本是否保留；关闭开关保存，可验证停用。

首次安装默认停用。插件没有额外依赖和后台任务，仅供验证安装与配置链路。

如果市场找不到插件，请确认仓库地址为 `https://github.com/xdong125/mppgdon`、MP 版本为 V3，并检查 MP 是否能访问 GitHub API 和 raw.githubusercontent.com。若安装失败，请提供 MP 完整版本号与脱敏插件错误日志。
